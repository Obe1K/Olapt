# Olá PT — европейский португальский для iPhone

Нативное приложение на SwiftUI (iOS 16+, только iPhone) для изучения **европейского** португальского (pt-PT). Работает офлайн, без сторонних библиотек, без сбора данных.

## Возможности
- **Словари** EN → PT(EU) и RU → PT(EU): ~9 400 слов и выражений, 50 тем, уровни A1–B2. Дополнительные словари подключаются импортом (CSV / TXT / JSON). Поиск понимает написание до реформы 1990 года (acção → ação, carácter / caráter).
- **Поиск** по португальскому, русскому и английскому, включая формы глаголов («falámos» → falar). Карточка слова: артикль, род, женская форма, множественное число, переводы из всех включённых словарей, бразильский вариант, озвучка pt-PT.
- **Коллекции** слов: из карточки, из готовых тематических наборов, со своими словами.
- **«Сегодня»** (первая вкладка): план дня — сколько слов повторить и сколько новых выучить (по умолчанию 10 в день из коллекций), ≈ минут; «на сегодня всё», когда план выполнен; прогноз повторений на неделю.
- **Интервальные повторения** FSRS-4.5 (`Models/Scheduler.swift`): слово возвращается, когда вероятность вспомнить падает до 90 %. «Выучено» — стабильность памяти ≥ 21 дня. Статусы «Новое → Учу → Выучено».
- **«Трудные слова»**: автоматическая коллекция из слов с 2+ ошибками, пока они не выучены.
- **2 уровня упражнений** в коллекциях: (1) выбор из 4 вариантов, направление вперемешку, следующее слово появляется само; (2) перевод → написать слово, буквы подсвечиваются зелёным/красным прямо при вводе. В плане «Сегодня» вид вопроса подбирается сам: новые и молодые слова — выбор, устоявшиеся — ввод.
- **Маг в башне** (тамагочи, `Models/Pet.swift`, `Models/PetStage.swift`, `Views/PetView.swift`): упражнения кормят, сытость падает на ~36 % в сутки. Сыт — башня, голодает — темница, 3+ дня — скелет. Этажи (подвал → зал → библиотека → вершина) открываются словами в памяти (стабильность ≥ 7 дней): 100 слов A1, 150 A2, 200 B1; каждые 50 слов — новая вещь в башне. Сцена 192×120 собирается из слоёв; пиксель-арт рисует `Tools/pet/hires.py`, `Tools/pet/export_hires.py` выгружает слои в `Assets.xcassets/Pet` и генерирует `Models/PetAtlas.swift`.
- **Босс недели** (`Views/BossArenaView.swift`): бой из слов с повторениями, 4 сердца у мага, здоровье босса = числу вопросов. Победа — полное зелье.
- **Гримуар** (`Views/GrimoireView.swift`): слова в памяти как книга заклинаний, сила 1–5 по стабильности.
- **Звуки** (`Models/SoundFX.swift`): 8-битные эффекты синтезируются на лету (AVAudioEngine), музыка по желанию; выключаются в настройках.
- **Тема**: тёмная пиксельная (`Views/Theme.swift`): камень, старое золото, кровь; шрифты Tiny5 и Jacquarda Bastarda 9 (OFL, `Resources/Fonts`).
- **Глаголы**: 1 329 глаголов × 15 форм (Presente, Pretérito Perfeito, Imperfeito, Mais-que-perfeito, Futuro, Condicional, Conjuntivo ×3, Imperativo, Infinitivo Pessoal, составные и т. д.) в формах Португалии (`estou a falar`, форма vós не используется). Тренировка спряжений с выбором и вводом, отдельный прогресс для каждой пары «глагол + время». Частые глаголы входят в план «Сегодня»: 4 новые пары в день плюс повторения.

## Как открыть и запустить
1. Нужен Mac с Xcode 26+ (с 28.04.2026 Apple принимает в App Store только сборки из Xcode 26+). Нет Mac — см. раздел 9 в `AppStore/01_PUBLISHING_GUIDE.md`.
2. Откройте `OlaPT.xcodeproj`, в *Signing & Capabilities* выберите Team и Bundle Identifier уже `com.obe1k.olapt`; Team выберите свой.
3. Выберите симулятор iPhone и нажмите ⌘R.

Полная инструкция по подписи, тестированию и отправке в App Store: `AppStore/01_PUBLISHING_GUIDE.md`.

### Если проект не открылся
Создайте новый проект *iOS → App* (SwiftUI) с именем OlaPT, удалите `ContentView.swift`, перетащите содержимое папки `OlaPT/OlaPT/` в проект (Copy items if needed), установите iOS 16.0 и только iPhone. Подробности — в руководстве по публикации.

## Как исправить или расширить встроенные слова
1. Отредактируйте файлы в `Tools/lexicon/`. Формат строки:
   `pt | pos [род] [f=женская форма] [pl=мн. число] | английский | русский | бразильский вариант | заметка`
   Заголовок темы: `## id | Название`.
   Части речи: `n, v, adj, adv, prep, conj, pron, det, num, interj, phrase`; род: `m, f, mf`.
2. Новый глагол: добавьте его в `lexicon/07_verbs.txt` как `v`. Нерегулярные глаголы описаны в `Tools/conj.py` (`IRREG`, `SPEC`). Все 15 форм строятся автоматически.
3. Запустите `python3 Tools/build_data.py` — скрипт предупредит о дублях и перепишет JSON в `OlaPT/Resources/`.
4. Пересоберите приложение.

## Формат импортируемого словаря
CSV/TXT (UTF-8): `слово; перевод 1 | перевод 2` в каждой строке; при импорте выбирается язык и название.
JSON — тот же формат, что у встроенных словарей:
```json
{ "id": "uk-pt-eu", "name": "Українська ↔ Португальська", "lang": "uk",
  "entries": [ { "pt": "casa", "pos": "n", "g": "f", "tr": ["будинок", "дім"] } ] }
```
Слова из разных словарей склеиваются по ключу «португальское слово + часть речи».

## Известные ограничения
- Проект собирается в Xcode 26 и проходит автотест всех экранов в симуляторе (GitHub Actions: `build.yml`, `ui-tests.yml`). На реальном iPhone он пока не запускался.
- Интерфейс только на русском.
- Форма vós в спряжениях не показывается.
- Голос pt-PT нужно скачать в iOS (Настройки → Универсальный доступ → Устный контент → Голоса); без него используется любой португальский голос.
- Лексикон составлен вручную и может содержать неточности; проверьте перед публикацией спорные слова носителем языка, если это важно для вас.
- Предупреждение о `onChange(of:perform:)` на новых SDK — безопасно.

## Конфиденциальность
Приложение не собирает данные и не использует сеть. Данные пользователя лежат в `Application Support/OlaPT/userdata.json` и `Dictionaries/` внутри песочницы приложения. `OlaPT/PrivacyInfo.xcprivacy` объявляет: без трекинга, без собираемых данных.
